# v0.1 Demo Notes

## Framing

This repository should be shown as a working v0.1 demo, not as a finished platform.

The message:

```text
AI agent logs can be turned into a small accident-investigation report.
This demo reads a sample JSONL session and produces static HTML + JSON findings.
```

Avoid saying:

```text
Complete AI agent observability platform.
Production-ready agent audit system.
Full OpenClaw / Hermes / Codex / Claude Code support.
```

## Primary Demo Artifact

Use the sample HTML report as the main visual.

Recommended flow:

1. Show `examples/sample-agent-session.jsonl`.
2. Run the CLI.
3. Show `reports/sample.html`.
4. Point at the findings: secret risk, dangerous command, repeated failure, evidence gap, unfinished work.

The screenshot should focus on the report, not the code.

## Current Demo Claim

```text
Agent Postmortem Kit v0.1 is a local-first working demo that turns a sample AI-agent session log into a postmortem report.
```

## Three Next Implementation Candidates

1. Add an AgentTrace JSON export adapter.
2. Add an OpenClaw adapter after reviewing representative local logs.
3. Add a local-only Oracle bundle command for second-opinion review prompts.
